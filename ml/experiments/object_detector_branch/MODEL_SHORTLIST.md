## Closed-set decision

The frozen detector-addressable objects are `bicycle` and `sports ball`; both are COCO classes. Calibration queries also contain common COCO concepts such as cell phone, backpack, dog, car, bus and cup. A closed-set detector therefore tests the current hypothesis directly with substantially lower compute and integration risk.

SceneMind's natural-language vocabulary is broader than COCO. Terms such as podium, projection screen, hole, title screen, classroom and semantic attributes such as yellow or red remain unsupported. The router must expose this limitation and preserve CLIP-only behavior when no supported object alias exists.

YOLO-World was considered as the lightest credible open-vocabulary direction, but its smallest official model card starts at the 640-pixel S family, requires text embeddings and uses GPL-3.0 code. Grounding DINO has a larger transformer and no official lightweight pinned ONNX path comparable to the 3.49 MiB YOLOX artifact. Neither is justified by the two COCO categories in the frozen failure inventory. They are excluded from this bounded experiment rather than treated as members of the runnable shortlist.

## Selection

The first real run uses the official YOLOX-Nano `0.1.1rc0` ONNX artifact with ONNX Runtime CPUExecutionProvider, four intra-op threads and one inter-op thread. Detection is limited to each query's existing CLIP top five. The model binary stays in ignored `data/models` storage; its byte size and SHA-256 are recorded in the experiment artifact.
