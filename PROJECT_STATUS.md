# Project status

Current milestone: core V1, Natural Video Benchmark V2, safe local hardening, isolated verifier/detector experiments, small-object and bounded-secondary ablations, coarse candidate diversity, and candidate-list ranking/no-match completed by 2026-09-15.

Completed: a checksum-verified CC BY 3.0 Big Buck Bunny pilot, disjoint calibration/held-out scenes, 16 reviewed query annotations, raw score/provenance reports, Recall/MRR at 1/3/5, negative false-accept and positive-abstention reporting, opt-in model-bound calibration and regression/leakage tests. Media remains ignored; no weights, embeddings or source videos are tracked.

Natural V2 adds five checksum-verified CC BY 3.0/4.0 natural videos from independent Wikimedia Commons source groups, 47 frozen annotations, complete held-out taxonomy, speech/visual/hybrid path comparisons, precision and latency, a query-path CSV, structured failures, and a version-aware regression gate. The three held-out videos never contribute to threshold fitting. Raw held-out visual R@1/3/5 is 71.4%/76.2%/85.7%; calibrated visual R@5 is 38.1%, negative FAR@5 is 10%, and positive false abstention is 52.4%. Speech R@1/3/5 is 60%/80%/80%, with 0% negative FAR and 0% positive false abstention. Hybrid raw R@5 is 77.8%; calibrated R@5 is 44.4%. See `ml/evaluation/NATURAL_V2_RESULTS.md` and `FAILURE_ANALYSIS.md`.

Verifier experiment: three additional checksum-verified Commons calibration videos add 30 frozen relation/context annotations, producing 25 positives and 21 negatives across the five-video calibration pool. BLIP ITM base COCO was tested as a batched second stage over CLIP's top five. Its calibration-only threshold 0.433838 reached 10% held-out negative FAR but repeated the current 52.4% positive false abstention, reduced held-out R@5 to 26.2%, and added 3.352 seconds median CPU latency with about 1.49 GB peak working set. It failed promotion; production code is unchanged and no second run was warranted. See `ml/evaluation/VERIFIER_RESULTS.md`.

Lightweight pair scorer experiment: two more checksum-verified Commons sources add 20 frozen phone/key/bag/cup and relation-focused calibration queries. The combined calibration pool has 66 queries across seven videos. Pinned UForm3 English small through ONNX reranks CLIP's top five in 202.1 ms warm median (229.1 ms p95), adds 163.1 MB isolated peak working set, and retains raw R@5. Its threshold reaches 0% held-out FAR but causes 47.6% positive false abstention. An eight-parameter CLIP-statistics logistic scorer takes 0.066 ms but causes 71.4% false abstention. Both fail promotion; the frozen run was not repeated and production remains unchanged. See `ml/evaluation/LIGHTWEIGHT_PAIR_SCORER_RESULTS.md`.

Object-detector experiment: a preselection inventory separates the three frozen small-object failures and shows that only the bicycle query has a top-five JPEG where every requested object is visibly present. Official Apache-2.0 YOLOX-Nano `0.1.1rc0` runs only on frozen CLIP candidates through ONNX Runtime. The calibration-only 0.8569 threshold yields 0% small-object negative FAR but 100% small-object positive false abstention. Raw candidate R@5 loss is 0 pp. Warm top-five median/p95 are 90.5/99.6 ms and added peak RSS is 58.0 MiB. It fails promotion; reranking, relationship proof, second run and production changes were skipped. See `ml/evaluation/OBJECT_DETECTOR_RESULTS.md`.

Small-object ablation: three new checksum-verified Commons sources and four frozen events separate sampled-frame visibility from detection. Exact JPEG review gives visible-evidence recall of 25%/100%/100% at 5/2/1 seconds. Frame counts grow from 47 to 116/230; combined extraction plus CLIP encoding grows from 8.00 seconds to 11.08/16.31 seconds. Fixed top-five CLIP candidate recall is only 25%/25%/50%, so denser sampling alone does not solve ranking. On the same 18 visible frames, manually target-box-reviewed recall is 66.7% for Nano 416, 83.3% for Nano 640 and 768, and 88.9% for RT-DETR-R18 640. Nano 640 has 32.5 ms p95 and 81.9 MiB added RSS; RT-DETR has 362.8 ms p95 and 552.5 MiB. Both higher-resolution Nano runs passed gates and repeated identically. Production remains unchanged; the next experiment is query-gated cached 2-second sampling with Nano 640 and wider candidates. See `ml/evaluation/SMALL_OBJECT_ABLATION_RESULTS.md`.

Bounded secondary experiment: the frozen 66-query calibration split selects top-5 coarse candidates with ±2-second windows and no spacing, averaging 9.1 secondary frames. On 31 held-out rows, bounded secondary CLIP reaches 81.0% R@5 versus 85.7% for global five-second CLIP; hypothetical global two-second CLIP reaches 76.2%. Human-reviewed held-out window recall is 50% and verified-visible secondary CLIP R@5 is 0%. Calibration selects zero detector weight. A 0.2780 no-match cutoff reaches 0% FAR but causes 81.0% overall and 100% small-object false abstention. The cache reuses 75% of 512 requests, holds 2.88 MiB, and averages 8.98 frames per routed query. Added median is 27.8 ms, p95 2.54 seconds from cold misses, and added peak RSS 84.3 MiB. Gates fail, no second run occurs, and production stays unchanged. Outcome C makes coarse candidate coverage the next task. See `ml/evaluation/BOUNDED_SECONDARY_RESULTS.md`.

Coarse candidate diversity experiment: real CLIP/FAISS retrieval over the frozen 66/31 split compares raw five/two-second candidates, temporal NMS, MMR, their combination, CLIP-change scene grouping and a bounded multi-scale diagnostic. Global two-second top five is more redundant (77.4% versus 69.0%), covers fewer temporal regions (2.94 versus 3.26), and loses three speech-label visual-path queries whose correct regions remain in top 20. Calibration selects a top-20, change-0.20, five-second-NMS multi-scale policy. It removes measured five-second-radius redundancy and preserves object/compositional/scene/action R@5, but held-out overall R@5 is 81.0% versus 85.7%, reviewed small-object recall stays 50%, speech drops 20 points and dense index growth is 2.40x. Gates fail, no second run occurs, and production stays unchanged. The two-second top-50 pool nevertheless reaches 97.6% correct-region and 100% reviewed small-object visibility recall. See `ml/evaluation/COARSE_CANDIDATE_RESULTS.md`.

Candidate-list ranking/no-match experiment: frozen five-second CLIP top-20/top-50 lists receive score/rank/distribution, temporal-support, embedding-agreement and visual-change features. Source-held-out calibration selects a 17-parameter logistic scorer, but its held-out R@5 is 76.2% versus the 85.7% raw baseline; top-50 Oracle is 100%. The query-level threshold reaches 0% held-out FAR by falsely abstaining on 90.5% of positives. Both quality gates fail although 0.44/0.96 ms median/p95 and 232 bytes of parameters pass resources. Existing explicit channel routing with real BM25 evidence reaches 95.2% R@5, so outcome E identifies routing as dominant. No second run or production change occurs. See `ml/evaluation/CANDIDATE_LIST_RANKING_RESULTS.md`.

Measured held-out results (four positives, four negatives): Recall@1=0.375, Recall@3=0.875, Recall@5=1.0; MRR@1=0.75 and MRR@3/5=0.8333. Calibration reduced false accepts from 4/4 to 2/4 with no observed positive-query abstention. The threshold was fitted only on the other scene. Two real-model runs matched quality metrics and passed the regression gate. This small single-film animated pilot is not broad natural-video quality; no speech/hybrid accuracy claim. See ml/evaluation/PILOT_RESULTS.md and reports/ for exact measurements. Synthetic rerun: both positives pass at K=1; its one negative still returns a neighbor.

Local hardening: optional shared-operator Basic/Bearer authentication, browser credential support, mutation Origin checks, SQL-backed durable queue, isolated persistent inference child, model reuse, attempt/backoff persistence, job listing/manual retry, process-tree deadlines, parent-death monitoring, single-host worker/execution locks, atomic queue capacity and duplicate protection. Existing upload byte/duration/resolution limits are retained. Serialized migrations support SQLite and PostgreSQL. Docker validation uses non-root Linux and a disposable internal PostgreSQL network; optional Compose stays loopback-only.

Executed checks: 81 Windows backend tests, Ruff, frontend ESLint, TypeScript and production build. The candidate-list real run rebuilt CLIP/FAISS top-50 lists, fit calibration-only rank/no-match models, audited existing CLIP/BM25/RRF paths, and measured resources. Earlier checks include the coarse-diversity, bounded-secondary, small-object, detector, pair-scorer, BLIP, Natural V2, browser, Linux and PostgreSQL validations described in their reports. Two upstream backend deprecation warnings remain; model runs report the existing slow-processor default warning.

Limits: one host/operator, no tenant ownership/RBAC, distributed workers, high availability or public deployment validation. API query inference remains in-process without a worker deadline. Delivery is at-least-once. A crash before enqueue may leave an unqueued upload asset; never silently delete user media. Inline mode preserves V1 limitations unless durable mode is enabled. Containerized real ML inference remains unverified. Natural V2 is a small diagnostic set, not a population estimate; pretraining overlap is unknown and timestamp boundaries have no tolerance. OpenCV VFR duration is approximate. Calibration remains opt-in and transfers poorly across the measured domains. No paid services, training, OCR, action recognition or Video RAG were added.

Next AI direction: keep production five-second CLIP order and explicit search modes. Improve mode guidance and collect source-disjoint speech calibration evidence before testing any automatic deterministic router. Consider a stronger semantic reranker only after routing is correct and a new frozen protocol exists; do not reuse the failed list/no-match threshold. Full public production hardening remains separate.
