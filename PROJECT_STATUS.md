# Project status

Current milestone: core V1 plus licensed evaluation/calibration and safe local hardening implemented on 2026-09-12.

Completed: a checksum-verified CC BY 3.0 Big Buck Bunny pilot, disjoint calibration/held-out scenes, 16 reviewed query annotations, raw score/provenance reports, Recall/MRR at 1/3/5, negative false-accept and positive-abstention reporting, opt-in model-bound calibration and regression/leakage tests. Media remains ignored; no weights, embeddings or source videos are tracked.

Measured held-out results (four positives, four negatives): Recall@1=0.375, Recall@3=0.875, Recall@5=1.0; MRR@1=0.75 and MRR@3/5=0.8333. Calibration reduced false accepts from 4/4 to 2/4 with no observed positive-query abstention. The threshold was fitted only on the other scene. Two real-model runs matched quality metrics and passed the regression gate. This small single-film animated pilot is not broad natural-video quality; no speech/hybrid accuracy claim. See ml/evaluation/PILOT_RESULTS.md and reports/ for exact measurements. Synthetic rerun: both positives pass at K=1; its one negative still returns a neighbor.

Local hardening: optional shared-operator Basic/Bearer authentication, browser credential support, mutation Origin checks, SQL-backed durable queue, isolated persistent inference child, model reuse, attempt/backoff persistence, job listing/manual retry, process-tree deadlines, parent-death monitoring, single-host worker/execution locks, atomic queue capacity and duplicate protection. Existing upload byte/duration/resolution limits are retained. Serialized migrations support SQLite and PostgreSQL. Docker validation uses non-root Linux and a disposable internal PostgreSQL network; optional Compose stays loopback-only.

Executed checks: 30 Windows backend tests; Ruff; frontend lint, TypeScript and production build; six desktop/mobile browser checks with actual CLIP inference, plus all six with operator authentication enabled. All 30 Linux backend tests passed against the final application/test source, and PostgreSQL migration/enqueue/claim/completion smoke passed. Benchmark preparation, both benchmark runners, calibration and metric regression gate ran successfully. Two upstream backend deprecation warnings remain; browser checks report existing image-priority and processor-default warnings.

Limits: one host/operator, no tenant ownership/RBAC, distributed workers, high availability or public deployment validation. API query inference remains in-process without a worker deadline. Delivery is at-least-once. A crash before enqueue may leave an unqueued upload asset; never silently delete user media. Inline mode preserves V1 limitations unless durable mode is enabled. Containerized real ML inference, broad natural footage, independently sourced held-out films and speech/hybrid quality remain unverified. OpenCV VFR duration is approximate. Calibration is opt-in and still accepts two held-out compositional negatives. No paid services, training, OCR, action recognition or Video RAG were added.

Next data milestone: independently reviewed source-disjoint natural footage with speech/hybrid labels and more compositional negatives, before changing model architecture. Full public production hardening remains a separate scope.
